- 責務
  - docker compose up コマンドの実装
  - Compose プロジェクトのコンテナを作成・起動する
- 処理の流れ
  - プロジェクト作成と起動
    - s.create
      - コンテナ作成
    - Attach == nil の場合は早期リターン
  - シグナルハンドリング設定
    - バッファサイズ 2
      - 1 回目の Ctrl+C = グレースフルシャットダウン
      - 2 回目 = 強制停止
    - atomic.Bool
      - 並行処理での安全な状態管理
  - ナビゲーションメニュー設定
    - keyboard.GetKeys
      - キーボードイベント取得
  - ファイル監視(Watch)設定
    - ファイル変更を監視して自動リビルド/リスタート
  - コンテキストとエラー管理の設定
    - errgroup.Group
      - 複数のゴルーチンのエラーを集約
    - appendErr
      - スレッドセーフなエラー収集
  - メインゴルーチン: シグナル処理
    - globalCtx.Done
      - グローバルキャンセル
    - ctx.Done
      - 親コンテキストのキャンセル
  - ウォッチャーの開始
    - watcher.Start
  - モニターの初期化
    - newMonitor
    - コンテナ終了時の処理
      - CascadeStop
        - いずれかのコンテナが終了したら全停止
      - CascadeFail
        - コンテナが失敗（非ゼロ終了）したら全停止
    - 終了コードのキャプチャ
  - コンテナへのアタッチ
    - s.attach
  - モニターとサービスの起動
    - monitor.Start
  - 終了処理
    - eg.Wait()
      - すべてのゴルーチンの完了を待つ
